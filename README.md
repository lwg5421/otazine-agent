# OTAZIN Agent — AI 뉴스 에이전트

애니메이션 뉴스를 자동으로 수집·작성·검토하는 3-에이전트 시스템

## 에이전트 구성

| 에이전트 | 역할 |
|---|---|
| 수집 에이전트 | Anime News Network RSS에서 최신 애니 뉴스 수집 |
| 작성 에이전트 | 원문 영어 기사를 Claude로 한국어 재작성 |
| 컨펌 에이전트 | 품질 검토 후 승인/반려 + 점수 |

## 페이지 구성

| 경로 | 내용 |
|---|---|
| `/` | 뉴스 목록 (수집 + 기사 작성 시작) |
| `/pipeline` | 처리 결과 (작성/검토 진행 상황, 읽기 모드, 복사) |
| `/logs` | 실시간 에이전트 로그 |

## 시작하기

1. 의존성 설치
```bash
npm install
```

2. 환경변수 설정
```bash
cp .env.local.example .env.local
# .env.local 파일에 ANTHROPIC_API_KEY 입력
```

3. 개발 서버 실행
```bash
npm run dev
# http://localhost:3000
```

## 사용법

1. **뉴스 수집** — 뉴스 목록 페이지에서 "뉴스 수집" 버튼 클릭
2. **기사 작성 시작** — 원하는 뉴스 카드의 "기사 작성 시작" 클릭
3. **자동 파이프라인** — 작성 에이전트 → 컨펌 에이전트 순서로 자동 실행
4. **결과 확인** — "처리 결과" 페이지에서 초안 + 컨펌 피드백 확인, "크게 보기"로 전체 화면 읽기
5. **수정 후 재검토** — 초안 직접 수정 후 "재검토 요청" 클릭 가능
6. **복사** — 완성된 기사를 클립보드로 복사해서 바로 게시 가능
